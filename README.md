# Housing Price Prediction Using Artificial Neural Network (ANN)

## 1. Introduction
This project focuses on predicting house prices using Artificial Neural Networks (ANN), a deep learning technique.

## 2. Objective
The main objective is to develop a model that predicts housing prices based on different housing characteristics.

## 3. Technologies Used
- Python
- Artificial Neural Network (ANN)
- Machine Learning
- Data Analysis

## 4. Project Description
The project uses housing-related data to understand the relationship between different features and house prices. An ANN model is used to learn patterns and make predictions.
