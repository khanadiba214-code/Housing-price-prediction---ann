# 🏠 Housing Price Prediction Using Artificial Neural Network (ANN)

## 📌 Project Overview
This project focuses on predicting residential property prices using Artificial Neural Networks (ANN) and Machine Learning techniques. It uses housing-related features to estimate property prices and demonstrates the application of Deep Learning in real estate analytics.

## 🎯 Project Objectives
- Analyse housing data and identify important price-related factors.
- Perform data preprocessing and feature engineering.
- Develop an Artificial Neural Network model.
- Train and evaluate predictive models.
- Estimate housing prices using trained models.
- Visualize housing trends and model performance.

## 📈 Model Evaluation
The model can be evaluated using the following regression metrics:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

Actual performance values should be added after running the model.
