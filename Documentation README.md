# Housing Price Prediction Using Artificial Neural Network (ANN)

## 1. Project Introduction
Housing Price Prediction is a Machine Learning project that aims to predict house prices based on different housing-related features using an Artificial Neural Network (ANN).

The project demonstrates how artificial intelligence and machine learning can help estimate property prices through data analysis and predictive modelling.

## 2. Aim
To develop an Artificial Neural Network model for predicting housing prices using relevant input features.

## 3. Objectives
- To understand and analyse housing data.
- To generate and preprocess housing datasets.
- To build an Artificial Neural Network model.
- To train and test the prediction model.
- To evaluate model performance.
- To predict house prices using trained models.

## 4. Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Artificial Neural Network

## 5. Project Modules

*Data Generation:* generate_data.py generates the housing dataset.

*Model Training:* run_models.py trains and evaluates the machine learning models.

*Price Prediction:* predict.py performs housing price predictions.

## 7. Applications

The project aims to develop a trained ANN-based prediction system that estimates housing prices from input features.
